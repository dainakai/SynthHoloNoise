フレーム 0

詳細設定 カメラ、区間、画素値の単位

基準は8-bitの1階調です。別の値域では、幅 ÷ 255 を振幅に掛けます。画面表示のコントラスト調整はダウンロード画像へ適用しません。

1024 × 1024以外の入力ではテンプレートを補間します。別の画素サイズや撮影装置を校正する処理ではありません。ブラウザ版は最大2048 × 2048、32 MBのグレースケール画像に対応します。

Pythonの計算環境を準備しています。初回はライブラリの読み込みに時間がかかります。

選択した画像はサーバーへ送信しません。Python環境はjsDelivr、プリセットはこのサイトから取得します。「次のフレーム」は同じ入力画像のままノイズの時間変化を表示します。

THE METHOD

形を引き継いで、
新しく生成する。

SHNは、背景除去後の実験ホログラムに残る構造を統計モデルとして使います。11撮影日、2台のカメラ、2つの時間区間から作った44個のテンプレートが基礎です。

抽出方法、数式、制限を読む ↗
  1. 01

    広い明暗むら

    実測テンプレートの回転、反転、位置移動。

  2. 02 / 03

    行と列の偏り

    横縞と縦縞の1次元テンプレートを位置移動。

  3. 04

    固定された細かな模様

    保存したフーリエ振幅と、新しいランダム位相から合成。

  4. 05

    時間的な揺らぎ

    周波数特性と画素値の分布を近似し、前フレームの模様と混合。

USE YOUR OWN HOLOGRAMS

Pythonから、そのまま。

静止画には1回の呼び出し。連続画像には、状態を保持するNoiseGeneratorを使います。

インストールと使い方 ↗
from synthholonoise import add_noise

noisy = add_noise(
    clean,
    preset="011",
    strength=0.5,
    seed=260628,
)
このモデルが表す範囲

同じ撮影装置と背景除去条件から推定した、画像への加算ノイズです。強度1は保存された成分係数を使う意味で、実験画像全体の標準偏差との一致を保証しません。光子数に応じたショットノイズ、絶対的な明るさの変化、別装置への適合はモデル化していません。
